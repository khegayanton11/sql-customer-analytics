# SQL Customer Analytics
Проект посвящен анализу клиентской базы и транзакций за период с 01.06.2015 по 01.06.2016.
Цель проекта — выявить поведение клиентов, оценить активность пользователей и рассчитать ключевые бизнес-показатели.
## Используемые инструменты
* Агрегатные функции
* JOIN
* LEFT JOIN
* GROUP BY
* HAVING
* CASE WHEN
* ORDER BY
* ROUND
## Выполненные задачи
### Анализ клиентской активности
* Определены клиенты с непрерывной активностью на протяжении года.
* Рассчитано количество операций по каждому клиенту.
* Выполнен анализ ежемесячной активности пользователей.
### Анализ финансовых показателей
* Рассчитан средний чек.
* Рассчитана средняя сумма покупок по месяцам.
* Определена доля операций и выручки по месяцам.
### Сегментация клиентов
* Выполнен анализ по полу клиентов.
* Проведена возрастная сегментация с шагом 10 лет.
* Рассчитаны показатели по каждой возрастной группе.
## Ключевые выводы
* Определены наиболее активные клиенты.
* Выявлены месяцы с максимальной активностью.
* Выполнена сегментация клиентской базы по полу и возрасту.
* Подготовлены данные для дальнейшего маркетингового анализа.
